# AsDecided Website

The public product site for [AsDecided](https://github.com/asdecided): local,
deterministic decision infrastructure for coding agents.

## Development

```sh
npm ci
npm run dev
```

Build and verify the deployable site with:

```sh
npm run build
npm test
```

The site is deployed through ChatGPT Sites. Technical documentation remains
owned by the repository that implements each product surface.
