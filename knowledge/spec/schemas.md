# Machine-readable schemas

The authoritative schemas are published in
[`asdecided/spec/schema`](https://github.com/asdecided/spec/tree/main/schema).

| File | Purpose |
|---|---|
| [`artifact.schema.json`](https://github.com/asdecided/spec/blob/main/schema/artifact.schema.json) | common artifact structure |
| [`frontmatter.schema.json`](https://github.com/asdecided/spec/blob/main/schema/frontmatter.schema.json) | identity and metadata envelope |
| [`artifact-specs.json`](https://github.com/asdecided/spec/blob/main/schema/artifact-specs.json) | artifact types, sections, and relationship fields |

Use the schemas with the
[conformance fixtures](https://github.com/asdecided/spec/tree/main/conformance)
when implementing another parser or consumer.
